VisionTrack ANPR Platform

AI-powered Automatic Number Plate Recognition and
multi-camera traffic analytics platform.

Status:
Prototype / Development

Technology:
Frontend: React + Vite
Backend: Node.js + Express
Database: SQLite
AI/OCR: YOLOv8 + CCT-XS OCR
Real-time Communication: Socket.IO
Maps & GIS: Leaflet
Deployment: Docker + Cloud deployment in progress

Run locally:
npm install
npm run dev
